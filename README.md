# BitVault — библиотека битов

Локальное веб-приложение для хранения и прослушивания битов из FL Studio.
Всё лежит в браузере (IndexedDB): аудио, обложки, `.flp` и метаданные никуда
не отправляются, сервера и аккаунтов нет.

## Возможности

- Загрузка аудио (mp3, wav, ogg, flac и др.) и файлов проектов `.flp`
  перетаскиванием или через кнопку «Добавить биты».
- Библиотека в виде сетки или списка: название, BPM, тональность, жанр, теги,
  заметки, обложка, цвет, избранное, дата, длительность, число прослушиваний.
- Переименование и редактирование любого бита, удаление с подтверждением.
- Поиск по названию/жанру/тегу, фильтр по тегу и избранному,
  сортировка по дате, названию, BPM и последнему прослушиванию.
- Встроенный плеер: play/pause, перемотка, громкость, следующий/предыдущий,
  пробел как play/pause.
- Экспорт и импорт всей библиотеки одним ZIP-архивом.
- Индикатор занятого места и запрос постоянного хранения.
- Тёмный «студийный» интерфейс, адаптивность, управление с клавиатуры.

## Стек

Vite 7, React 19, TypeScript 5.9, Tailwind CSS 4, IndexedDB через `idb`,
ZIP через `fflate`, Vitest + Testing Library.

## Команды

```bash
npm install
npm run dev
npm run build
npm run preview
npm run lint
npm run typecheck
npm test
```

Требуется Node.js 20.19+ (проверено на Node 22).

## Ограничения

- `.flp` хранится как вложение: браузер не умеет его воспроизводить или
  разбирать, поэтому карточка проекта доступна для скачивания.
- BPM и тональность вводятся вручную, автоопределения нет.
- Нет облачной синхронизации и аккаунтов: данные живут только в этом браузере.
- Квота браузера ограничена; приложение предупреждает о заполнении хранилища.
  Регулярно делайте экспорт библиотеки как резервную копию.
- Один архив импорта ограничен 10 000 треков и 2 ГБ файлов (до 50 вложений на
  трек); записи вне каталога `files/` не распаковываются, а импорт блокируется,
  пока идёт загрузка новых файлов. Экспорт откажется создавать архив, который
  сам не сможет импортировать, — удалите лишние файлы перед резервной копией.
- Основные браузеры — Chrome и Edge; Firefox и Safari поддерживаются по мере
  возможностей (Safari может вытеснять данные неактивных сайтов).

## Приватность

Приложение не делает сетевых запросов: шрифты и все ресурсы лежат в сборке,
файлы битов не покидают устройство. API-ключей и внешних сервисов нет.
