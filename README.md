# BitVault — библиотека битов

Локальное веб-приложение для хранения и прослушивания битов из FL Studio.
Всё лежит в браузере (IndexedDB): аудио, обложки, `.flp` и метаданные никуда
не отправляются, сервера и аккаунтов нет.

## Как запустить

Готовый сайт уже опубликован — устанавливать и запускать ничего не нужно:

1. Откройте **https://paluuwp.github.io/bitvault/** в Chrome, Edge, Firefox
   или Safari.
2. Нажмите «Добавить биты» и выберите аудиофайлы (mp3, wav, ogg, flac и др.)
   или проекты `.flp` — их также можно перетащить в окно.
3. Заполните название (BPM, жанр и теги — по желанию) — бит появится
   в библиотеке.

Библиотека хранится в браузере (IndexedDB), на сервер ничего не отправляется,
у каждого человека она своя. Приложение можно установить на компьютер или
телефон и открывать офлайн — см. раздел «Установка как приложение (PWA)».

**Локальный запуск из исходников.** Нужен Node.js 20.19+:

```bash
npm install
npm run dev
```

Затем откройте `http://localhost:5173/`. Остальные команды — в разделе
«Команды».

## Возможности

- Загрузка аудио (mp3, wav, ogg, flac и др.) и файлов проектов `.flp`
  перетаскиванием или через кнопку «Добавить биты».
- Библиотека в виде сетки или списка: название, BPM, тональность, жанр, теги,
  заметки, обложка, цвет, избранное, дата, длительность, число прослушиваний.
- Переименование и редактирование любого бита, удаление с подтверждением.
- Поиск по названию/жанру/тегу, фильтр по тегу и избранному,
  сортировка по дате, названию, BPM и последнему прослушиванию.
- Встроенный плеер: play/pause, перемотка, громкость, следующий/предыдущий,
  пробел как play/pause.
- Экспорт и импорт всей библиотеки одним ZIP-архивом.
- Индикатор занятого места и запрос постоянного хранения.
- Тёмный интерфейс в духе FL Studio: графитовые панели, оранжевый акцент,
  LED-индикаторы, моноширинные счётчики BPM и времени; адаптивность,
  управление с клавиатуры.
- Устанавливается как приложение (PWA) и работает офлайн; новая версия
  предлагается плашкой «Обновить», без принудительной перезагрузки.

## Стек

Vite 7, React 19, TypeScript 5.9, Tailwind CSS 4, IndexedDB через `idb`,
ZIP через `fflate`, Vitest + Testing Library.

## Установка как приложение (PWA)

Приложение собирается как PWA: его можно установить на компьютер или телефон,
и после первого открытия оно работает офлайн — без интернета и без запуска
чего-либо на вашем компьютере. Библиотека по-прежнему хранится локально в
браузере, у каждого человека она своя.

- **Chrome / Edge на компьютере:** значок «Установить» в адресной строке или
  меню ⋮ → «Установить приложение». После установки BitVault открывается в
  отдельном окне без адресной строки.
- **Android:** меню браузера → «Установить приложение» / «Добавить на главный
  экран».
- **iPhone / iPad (Safari):** кнопка «Поделиться» → «На экран “Домой”». iOS
  открывает PWA в отдельном окне, но без установки офлайн-режим ограничен —
  добавляйте на домашний экран.

### Обновления

При каждом деплое выходит новая версия. Приложение проверяет её при запуске и
при возврате на вкладку; когда обновление готово, сверху появляется плашка
«Доступна новая версия BitVault». Нажмите «Обновить» — страница перезагрузится,
библиотека и файлы останутся на месте. Пока идёт загрузка, импорт или экспорт,
кнопка «Обновить» заблокирована, чтобы не прервать операцию. «Позже» скрывает
плашку; она появится снова при следующем запуске или когда выйдет следующая
версия.

Удаление ярлыка приложения данные не стирает: библиотека живёт в хранилище
браузера, а не в ярлыке. Но «Очистить данные сайта» в браузере удалит всё —
регулярно сохраняйте ZIP-копию через «Настройки» → «Экспортировать
библиотеку».

## Ограничения

- `.flp` хранится как вложение: браузер не умеет его воспроизводить или
  разбирать, поэтому карточка проекта доступна для скачивания.
- BPM и тональность вводятся вручную, автоопределения нет.
- Нет облачной синхронизации и аккаунтов: данные живут только в этом браузере.
- Квота браузера ограничена; приложение предупреждает о заполнении хранилища.
  Регулярно делайте экспорт библиотеки как резервную копию.
- Один архив импорта ограничен 10 000 треков и 2 ГБ файлов (до 50 вложений на
  трек); записи вне каталога `files/` не распаковываются, а импорт блокируется,
  пока идёт загрузка новых файлов. Экспорт откажется создавать архив, который
  сам не сможет импортировать, — удалите лишние файлы перед резервной копией.
- Основные браузеры — Chrome и Edge; Firefox и Safari поддерживаются по мере
  возможностей (Safari может вытеснять данные неактивных сайтов).
- Service worker регистрируется относительно папки приложения, поэтому
  открывайте BitVault по адресу развёртывания (`https://…/bitvault/`), а не по
  вложенному пути вида `/bitvault/a/b` — там офлайн-режим не активируется.

## Приватность

Приложение не обращается к сторонним сервисам: шрифты и все ресурсы лежат в
сборке, файлы битов не покидают устройство. Единственные сетевые запросы — за
статикой самого приложения и его service worker с того же адреса (это нужно
для установки и обновлений PWA). API-ключей и внешних сервисов нет.
